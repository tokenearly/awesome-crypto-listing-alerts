# Contributing

Thanks for helping keep this list useful. Open a pull request that edits `README.md`.

## What belongs here

- Services, pages, channels, code and articles that help people learn about **crypto exchange listings** (and closely related announcements: delistings, trading-pair launches, launchpools).
- Anything listed must be **live**: the link works today and, for software, the repository has been updated within the last 2 years or is clearly still functional.
- Official exchange resources only in the "Official" sections. Community channels go under "Open-source bots and scripts" or "Reading" if they fit, otherwise they are out of scope.

## Entry format

```
- [Name](https://link) — one neutral sentence: what it does, which exchanges, how it delivers.
```

- One entry per line, alphabetical within its section unless the section is a table sorted by exchange.
- Describe, do not advertise: no "best", "fastest", "#1". If you are the author of the project, say so in the PR description.
- No affiliate or referral links, no shorteners, no tracking parameters.
- Commercial services are welcome (this list already contains several, including the maintainer's own Tokenearly) as long as the description is factual and the free/paid nature is stated.

## Removing entries

Open an issue or PR if a link is dead, a project is abandoned, or a description is inaccurate. Include what you checked and when.

## Checklist for pull requests

- [ ] Link returns a real page (not a 404 or a parked domain)
- [ ] Description is one sentence, factual, in English
- [ ] Entry is in the right section and in order
- [ ] `Last updated` date in `README.md` bumped to today
- [ ] By contributing you agree your contribution is released under CC0 1.0 (see `LICENSE`)
